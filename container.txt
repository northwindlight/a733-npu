# ACUITY / pegasus 转换容器。
#
# ★按 digest 钉住，不要改回 `:v2.0.10.1` 这种可变 tag。
#   这是整个仓库唯一不可恢复的依赖：镜像在私有 ghcr 上，一旦那个包被删，
#   仓库就永久失去构建能力，且既有产物都无法解释。
#   而且**没法用 Release 兜底** —— GitHub 单文件 Release 附件上限 2 GiB，镜像是 2.7 GB。
#
# 换镜像时的两步：
#   1. docker pull ghcr.io/northwindlight/ubuntu-npu:<新tag>
#   2. docker inspect --format='{{index .RepoDigests 0}}' ghcr.io/northwindlight/ubuntu-npu:<新tag>
#      把输出的 @sha256:... 整串粘到下面
#
# 当前 digest 对应 tag v2.0.10.1（解析于 2026-09-27）：
ghcr.io/northwindlight/ubuntu-npu@sha256:fb2a946c8201594ce1167e2a5c133a2a00b4aa98cde923209c5523fcdfb30729
